# HomeGuard móvil en Flutter

App nativa Android/iOS con las funciones disponibles del backend, sin agregar cámaras ni sensores. La versión Expo anterior queda en ../mobile-app.

Consultá [FLUTTER-MOVIL.md](FLUTTER-MOVIL.md) para instalar el APK, conectar tu teléfono, configurar Firebase y compilar.

```powershell
flutter pub get
flutter analyze
flutter test
flutter run
```

Desde la raíz del repositorio: `./Compilar-AppFlutter.ps1` y `./Iniciar-AppFlutter.ps1`.
